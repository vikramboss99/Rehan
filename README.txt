ZAYN REHAN — 6-PAGE BIRTHDAY WEBSITE

1. Extract the ZIP file.
2. Open index.html in Chrome or another modern browser.
3. To publish: upload all 8 files (index.html, page2.html through page6.html, style.css, app.js) together to a GitHub Pages repository or any static web host.
4. Keep all files in the same folder.
5. Sounds play only after user interaction due to browser autoplay rules.
6. Internet is needed for Google Fonts; the website and games otherwise work offline.
